# pytest Cheatsheet

This is a little cheatsheet that captures many of the common pytest arguments, and
arguments to common plugins, on one printable page.

Inspired by (and template copied from) [nblock/pdb-cheatsheet](https://github.com/nblock/pdb-cheatsheet).

You can download a PDF copy from the [releases](https://github.com/adcox/pytest-cheatsheet/releases)
